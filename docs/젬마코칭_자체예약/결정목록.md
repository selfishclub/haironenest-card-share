# 결정목록 — 을한 님이 정할 것

클로드는 이 목록의 "미정"을 버전 시작 전에 하나씩 묻습니다. 고를 수 있는 안, 추천과 이유를 보여 주지만 **정하는 사람은 을한 님**입니다. 정하면 "을한 님 답"과 "이유", 날짜를 채우고 상태를 `정함`으로 바꿉니다. 나중에 바꾸면 줄을 지우지 말고 `바꿈(날짜): 새 답 — 이유`를 덧붙입니다.

상태: `미정` · `정함` · `미룸`(다음 버전에서 다시)
