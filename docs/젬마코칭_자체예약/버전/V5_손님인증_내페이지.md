# V5 손님 인증 · 내 페이지

> 언제: 2월 이후 · 장기 과제 · 시작할 때 자세히 다듬습니다

## 끝나면 보이는 장면

손님이 번호를 넣고 문자로 받은 인증번호를 넣으면 내 페이지가 열립니다. 내 예약, 지난 시술, 다음 권장 시기가 보이고, 거기서 바로 다음 예약을 잡습니다.

## 먼저 정할 것

D5-1 ~ D5-3. 개인정보처리방침을 먼저 고칩니다.

## 만드는 것

- 문자 인증번호: 6자리, 5분 유효, 번호당·하루 시도 제한, 틀리면 잠시 잠금
- 내 페이지: D5-2에서 정한 칸만. 원장님 진단 메모는 보이지 않음
- "다음 권장 시기"는 지금 카드의 권한 주기(예: 5주 → 11.03쯤)를 그대로 씀

## 살필 위험

- 전화번호 뒷자리만으로 여는 길을 만들지 않음
- 인증번호 문자 비용이 늘어남 → 개인 링크로 되는 일(예약 보기·취소)은 인증 없이 그대로 둠
- 상담 기록이 손님 화면으로 나가는 첫 버전이라 보여 줄 칸을 원장님이 하나씩 확인
