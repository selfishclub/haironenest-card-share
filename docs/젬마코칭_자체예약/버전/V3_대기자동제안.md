# V3 대기 자동 제안

> 언제: 12월 3~4주 · 누가 쓰나: 자체 예약 요일의 대기 손님 · 시작할 때 자세히 다듬습니다

## 끝나면 보이는 장면

손님이 링크로 취소하면, 원장님 손 없이 맞는 대기 손님 한 명에게 그 자리가 잡히고 "예/아니요" 문자가 갑니다. 예를 누르면 확정, 아니요나 시간이 지나면 다음 손님에게 넘어갑니다. 잡아 둔 동안 예약 페이지에는 그 시간이 안 보입니다.

## 먼저 정할 것

D3-1 ~ D3-5.

## 만드는 것

- 취소 → 빈 시간 계산(앞뒤 빈칸까지) → 맞는 대기 손님 고르기(지금 `matchWaiters`를 실제 빈 시간 기준으로)
- 잡아 두기: `card_bookings`에 held 줄 + `hold_until`
- 예/아니요 링크(개인 링크와 같은 방식)
- `api/tick`: 시간 지난 held를 풀고 다음 손님에게. 밤 시간(D3-3)은 멈춤
- 5분 타이머(D3-4). GitHub Actions라면 `.github/workflows/`에 파일 하나와 비밀 값 하나
- 원장님 화면: "지금 잡아 둔 자리" 줄

## 넘어가는 조건

- [ ] 취소 자리 중 대기로 채워진 비율이 진행기록에 나옴
- [ ] 잘못 잡힌 자리 0(같은 시간에 held 둘, 시간이 지났는데 안 풀림 등)
- [ ] 원장님이 대기 때문에 손댄 횟수 0

## 살필 위험

- 타이머가 몇 분 늦을 수 있음 → 가장 짧은 잡아 두기가 20분인 이유
- 같은 손님에게 같은 자리를 두 번 제안하지 않게
- 문자 비용: 취소 한 건에 최대 D3-2명
