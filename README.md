# 헤어원네스트 상담 카드 — 젬마 선생님 코칭 공유용

평택 1인 미용실 헤어원네스트 원장이 젬마 선생님 수업에서 배워 직접 만들고, 매장에서 매일 쓰는 고객 상담 카드입니다.
이 저장소는 코칭을 받으려고 만든 **공유용 사본**입니다(2026-10-29 기준). 코칭이 끝나면 비공개로 돌립니다.

- 실제로 돌아가는 카드는 따로 있는 비공개 저장소에서 배포됩니다. 이 사본을 고쳐도 매장 카드는 바뀌지 않습니다.
- 실제 고객 이름·번호·사진·백업 파일·비밀 키는 들어 있지 않습니다. 시험 자료의 이름은 전부 "예시…", 번호는 가짜입니다.
- 워크숍 과제·발표자료·운영 계획 문서(`docs/`)는 빼고 올렸습니다. `CLAUDE.md`에 `docs/…`가 나오면 그 폴더를 가리킵니다.

## 둘러보는 법

- **화면:** https://haironenest-card.vercel.app/?local=1 → 오른쪽 위 [예시 손님 넣기]. 로그인 없이 가짜 손님으로 모든 화면을 볼 수 있고, 그 브라우저에만 저장됩니다.
- **규칙 전부:** [`CLAUDE.md`](CLAUDE.md). 클로드 코드가 이 저장소에서 일할 때마다 읽는 작업 규칙이고, 기능마다 원장이 정한 이유와 날짜가 적혀 있습니다.
- **만들어 온 순서:** [`작업기록.md`](작업기록.md) — 82건, 2026-09-29 ~ 10-28.
- **예전 사용 설명:** [`README_매장용.md`](README_매장용.md) (V3 이전에 쓴 것이라 일부는 지금과 다릅니다).

## 짜임

| 파일 | 하는 일 |
|---|---|
| `store.js` | 저장 규칙 전부(순수 함수). 화면·서버를 모른다 |
| `db.js` | 바뀐 줄만 Supabase에 올리고 읽어 와 조립한다. 로그인 |
| `app.js` | 그리기와 단추 |
| `index.html` | 화면 틀과 모양 |
| `wait.html` | 손님이 로그인 없이 쓰는 예약 대기 페이지 |
| `api/` | Vercel 서버 함수: 대기(`wait.js`), 대기 문자(`sms.js`), 전날 알림톡(`remind.js`), 공통(`_lib.js`) |
| `supabase/schema.sql` | 서버 표(전부 `card_` 접두어), 사진 창고, 자물쇠(RLS) |
| `*.test.js` | 자동 시험 281개 — `npm test` |

정적 파일 + Supabase + Vercel. 설치할 패키지는 없습니다. 비밀 키(발송킹·Supabase 서비스 키)는 Vercel 환경 변수에만 있습니다.

## 만든 기능 (원장이 요청한 날짜)

### 상담 기록 (카드의 핵심)
- 말한 그대로 받아 적으면 **고민 / 진단 / 시술 / 주기 / 다음 계획** 다섯 항목으로 나눠 저장 (09-29 ~ 10-01)
- 이름 옆 고정 정보(고객이 한 말·생활 / 얼굴형·모질·두상), 방문 주기 "권한 주기 5주 → 11.03쯤" (09-30)
- 사진은 동의 받은 손님의 기록에만, 적다 만 글은 브라우저에 임시 보관, 지우기는 두 단계

### 메인 화면과 단추
- 처음 화면을 분류 상자 여섯(오늘 손님·고객 관리·예약관리·재고관리·결산·고객 채팅)으로, 할 일 수가 빨간 딱지로 (10-26)
- 타임테이블이 오늘 명단 — 빈 칸을 눌러 시간·시술·이름으로 올리기, 시술 길이만큼 막대, 기록 남기면 초록 (10-13)
- 내일 예약 미리 올리기, 번호 없는 손님 표시 (10-14) / 막대 밑에서 시간·시술 고치기 (10-23)
- 시술항목 관리 — 분류(커트 → 남성·여성·아이 컷)·걸리는 시간·금액, 더하기·고치기·지우기·순서 바꾸기 (10-13 ~ 10-24)
- 결산을 분류 상자로 — 큰 숫자·지난달 비교, 누르면 자세히 (10-26)

### 고객 관리
- 찾기·등록·고객 동향(신규·재방문·다시 올 때 된 고객·정액권 남은 고객) (10-08)
- 정액권 안내문 — 예약한 시술이 미리 들어가고 분류 → 세부 시술로 고르기 (10-09, 10-24)
- 가족 묶기 — 정액권 잔액 함께 쓰기(10-07), 함께 오는 가족 탭·관계·대표(10-24 ~ 10-28), 대신 온 가족으로 예약 바꾸기(10-27)
- 선예약 연락 — 말일 2일 전 대상 손님에게 손님마다 추천 날짜를 넣은 문구 복사·문자 (10-09, 10-28)

### 예약 알림톡과 대기
- **전날 오후 6시 예약 알림톡** — 카드에 올린 내일 예약 그대로 발송킹으로 자동 발송, 카톡 실패 시 문자, 손님별로 갔는지 카드에서 확인 (10-21 ~ 10-26)
- **예약 대기** — 손님이 로그인 없이 희망 월·평일/주말·오전/오후/5시 이후·시술로 대기를 건다. 원장이 취소를 한 줄 적으면 빈 시간에 들어가는 시술의 대기자 앞 3명에게 문자, 받은 사람은 줄 맨 뒤로 (10-11, 10-23)
- 취소 적기 — 말하듯 한 줄("15일 2시 콜드펌 취소, 채워짐")을 날짜·시간·시술·채워짐으로 읽음 (10-11)
- 예약관리 화면을 아이콘 단추 다섯으로 (10-23)

### 재료 주문과 재고
- 개수만 센다 — 들어온 것과 한 달에 한 번 센 것으로만 숫자가 움직임, 말로 센 글 읽기(색상 번호 "7.07"은 이름으로) (10-01 ~ 10-03)
- 거래처별 주문 글 — 채워 둘 개수에서 모자란 만큼, PC는 복사·핸드폰은 카톡 공유 (10-06, 10-08)
- 도착 확인 체크박스 (10-15), 월별 재고표와 채워 둘 개수 제안 (10-09)

## 지금 막힌 곳 (코칭에서 여쭐 것)

취소 자리가 나면 대기 손님에게 그 자리가 **잡혀 있고** 손님은 예/아니요만 누르는 방식을 원합니다. 하지만 빈자리를 잡아 둘 수 있는 곳은 네이버 예약 달력뿐이고, 카드는 그 달력을 읽지도 막지도 못합니다. 그래서 지금은 "자리가 났어요" 선착순 문자에서 멈춰 있습니다. 시술별로 시간을 막는 일도 아직 핸드SOS(네이버 제휴 프로그램)에 기대고 있습니다.
